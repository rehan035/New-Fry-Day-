# Fry Days — Official Restaurant Website

Official responsive web application for **Fry Days** (`W Canal Road, Jahan E Andalus, Faisalabad, Pakistan`).

## Features
- **Complete Official Menu (16 Categories, 47 Items)**:
  - **All-Time Favorites**: Burgers (*Zesty Zinger*, *Fire Cracking*, *Jalo Blast*, *Krunch Munch*, *Stack It Up*, *Charcoal Fire Grill*), Wings, Wraps (*Wrapstar*, *Hot Grilled*), and Chips & Wings.
  - **Injected Chicken Broast**: *Quarter*, *Half*, *Full*, *2 Full*, and *3 Full* Broast platters.
  - **Awesome Fries**: *Hand-Cut Fries* (Plain, Masala), *Signature Fries* (Garlic Mayo, Hot Garlic Mayo), *Twisto Fries*, *Loaded Fries* (*Fryday's Special*, *Flaming Hot Buffalo*, *Crispy Attack*, *Smokey Grilled*), and *Pizza Fries*.
  - **Combos & Promotional Deals**: *Twin Zinger Combo*, *Fantastic Four*, *Full House Feast*, *Double Treat Combo*, *Wrap N Wing Feast*, *Lunch Combos (12 PM – 4 PM)*, *Midnight Combos (11 PM – 2 AM)*, *The Boss Deal*, *Azadi Deal (with Free Loaded Fries selector)*, and *Wacky Wednesday*.
  - **Extras, Dips & Beverages**: *Bun*, *Cheese Slice*, 6 signature *Dips*, *Cold Drinks*, *Water*, and *Fantastic Tea — Plain Tea*.
- **Interactive Order Bag & Instant WhatsApp Checkout**: Select sizes, spice levels, and add-ons, and send formatted orders directly to `+92 326 1180202`.
